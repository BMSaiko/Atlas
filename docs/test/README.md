## How the harness splits work

- `_atlas-runtime.mjs::spinAtlas()` — Vite middleware + atlas-api in-process. Used by 19 tests. Hermetic tempdir.
- `_atlas-harness.mjs::spinAtlasHarness()` — real `launchHermes` spawn (Python + git worktree + close handler). Used only by `run-integration`. **Skipped on CI** because it needs a real filesystem layout.
- No helper — pure unit tests with their own custom runner. Used by 12 tests.

## Adding a new test

1. `test/<name>.test.mjs` (must `process.exit(0|1)`).
2. `docs/test/<name>/README.md` (copy any existing one).
3. `node scripts/check-test-docs.mjs` → OK.
4. `npm test` → OK.
